## 二、3 个月时间线

### Month 1：把项目变成面试武器

**目标：让面试官在 5 分钟内理解你在做什么、为什么有意思、你做了什么。**

**1. 写好 README（1 天）**

你的 GitHub repo 目前没有 README 文件。必须写一个，包含：

```
1. 一句话简介（GRPO 训练做市商/执行端）
2. 训练结果（MM Phase 1: +0.038，对比论文的 -0.2）
3. 项目结构图
4. 快速启动命令
5. 实验结果表格
```

**2. 写好面试用的项目介绍（反复练）**

准备一个 **2 分钟** 和 **5 分钟** 版本：

```
2 分钟版：
  "我实现了一个基于 JAX 的 GPU 加速多 agent RL 框架，
   用 GRPO 算法训练做市商和执行端。
   核心贡献是发现了 A 股 T+1 环境下做市商的盈利条件，
   在模拟器中达到了单做市商 +0.038 tick 的正收益，
   超过了原论文（亏损 0.2 tick）。

   训练过程我发现关键瓶颈是数据质量（缺撤单和新订单），
   以及多 agent 环境下的零和博弈问题。
   我设计了一个分层训练方案解决了这个问题。"

5 分钟版：
  加训练细节：ENT_COEF 调参、z-score 归一化的影响、
  数据格式对比、Phase 1/Phase 2 设计。
```

**3. 把代码和结果整理到一个可展示的状态（3 天）**

- 关键的训练曲线截图（wandb）
- 对比表格（论文 vs 你）
- 放进去一个能跑的最小例子（如果面试官想看的话）

## 三、这个项目在面试中怎么用

### 面试官最可能问的

| 问题 | 你应该怎么答 |
|------|------------|
| "做市商怎么赚钱？" | 价差、库存管理——讲你的 MM 怎么学到的 |
| "为什么用 RL 不是规则？" | 市场动态非平稳，RL 自动适应 |
| "RL 训练有什么问题？" | 零和博弈、entropy 坍缩、数据质量——你都亲自踩过 |
| "JAX 比 PyTorch 好在哪？" | 函数式编程+JIT+vmap，适合环境仿真 |
| "GRPO 和 PPO 区别？" | 去 critic、group advantage——你能讲清楚 |
| "遇到过什么困难？" | Phase 2 全被冻结了、z-score 归一化问题——**记住 bug 也是亮点** |
| "结果可靠吗？" | 数据缺陷、需要 LOBSTER 验证——**诚实比吹牛好** |

### 你的简历上写什么

```
关键项目：JaxMARL-HFT — GPU 加速的 MARL 高频交易模拟器
- 基于 JAX 实现 GRPO 算法，在 4 卡 GPU 上并行训练做市商/执行端
- 设计 A 股 T+1 适配的 reward 函数，单做市商收敛到 +0.038 tick
- 发现多 agent 零和博弈问题，设计分层训练方案
- 对比分析数据格式缺陷（LOBSTER vs 快照转换）对训练的影响
- 技术栈：JAX、Flax、Python、wandb、CUDA
```
